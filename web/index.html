KeyPill Hardware Device Profile

Microcontroller: STM32F103C8T6 (72 MHz ARM Cortex-M3)
Cryptographic Engine: AES-128 NIST FIPS 197 (CBC / ECB)
Non-Volatile Storage: Internal Flash Page 63 (0x0800FC00)
Physical Entropy: Floating ADC (PA3) + SysTick + 96-bit UID
Input Interface: EC11 Rotary Encoder + 0.96" SSD1306 OLED
Transport Method: USB HID Keyboard / SWD Mailbox
